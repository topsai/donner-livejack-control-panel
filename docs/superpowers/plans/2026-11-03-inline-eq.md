# Inline EQ editors

Use a shared reusable WPF Border editor instead of a microphone Window. Embed the input editor below input strips and the output editor below output strips. Input buttons select and scroll to the embedded editor. Preserve microphone DSP, settings and native callback lifetime. Output uses the existing Banana bus EQ and pending-write/readback mechanism, not microphone DSP. Preserve bus selection, left/right selection and linked writes. Both editors use EqGraph nodes/numeric input and filter selection; output respects native gain ±12 dB and Q 1–100, microphone gain ±24 dB and Q .1–20. Hidden editors stop graphical polling; hiding or changing tab never disables active DSP. No extra windows, no fake output spectrum. Native filter type mapping follows ordered official EQPro-G6 symbols (Bell, Notch, BandPass, LowPass, HighPass, HighShelf, LowShelf).
