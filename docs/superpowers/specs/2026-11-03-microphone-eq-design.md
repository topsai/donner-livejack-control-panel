# 独立麦克风参数 EQ

用户选择专业参数 EQ，界面参考所附频响曲线截图。基于现有 WPF/C# 工程与 Banana Remote 输入插入回调（mode 1 / command 10）；不使用总线 EQ 替代独立人声处理，不新增驱动或录音文件。

每个硬件输入 1–3 独立保存六段设置，两声道同步处理，伴奏和其他输入原样传递。默认关闭；在硬件输入下点击“麦克风 EQ”打开深色独立编辑窗口，再勾选启用。提供 20–20000 Hz 对数横轴、±24 dB 纵轴、彩色可拖动节点、黄色总曲线、灰色实时频谱，选中频段后编辑类型、频率、增益、Q；滚轮调 Q。滤波类型包括 Bell、低切、高切、低架、高架、陷波；旁通、恢复平直和输出增益。频谱仅取实际输入，不做模拟。默认六个 Bell 为 80/200/600/1500/4000/10000 Hz，增益 0、Q 1，开关关闭。

DSP 使用 RBJ biquad 系数，独立声道状态，参数更新/旁通作约 10 ms 双链交叉淡化。回调不访问 UI、磁盘、日志和阻塞锁，不分配托管数组。所有输入指针先复制到输出，非目标声道保持不变。采样率变更时先旁通，UI 重新发布系数；连接断开/重启显示状态并可重新连接。已被其他程序占用的输入插入接口不得抢占。

参数保存在本面板 AppData；保存参数，不保存自动启用状态，每次启动默认旁通以免对用户现有直播造成意外改变。窗口关闭不关闭已启用 EQ，退出面板/停用调音台时停止并注销回调，恢复 Banana 原输入处理。关闭编辑器时明确显示此提示。配置损坏回退平直旁通，不覆写损坏文件直到用户明确修改。

可自行决定图表尺寸与标准 WPF 控件细节。初版不做第三方 VST 宿主、动态 EQ、左右独立编辑和预设库。真实回调先以全旁通验证通道数、帧率与退出清理；效果正确性使用离线正弦波及缓冲隔离测试，真实麦克风听感由用户确认。
