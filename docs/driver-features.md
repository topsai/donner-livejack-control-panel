# 原厂驱动功能

功能依据 Donner Livejack 原厂 5.0.0 驱动接口及当前硬件查询结果。

| 功能 | 支持情况 |
|---|---|
| 采样率、ASIO 缓冲和延迟 | 按驱动返回的能力显示 |
| 通道音量和静音 | 两路输入、左右输出 |
| 输出位深 | 16/24 位 |
| 输入格式 | 24 位、双通道 |
| ASIO 安全模式 | 可切换；调缓冲保留当前模式 |
| 音频流模式 | 按需或持续开启 |
| 时钟和客户端状态 | 内部时钟锁定、WDM/ASIO 占用计数 |

右上角齿轮 → 驱动设置。未成功读取的功能隐藏；更改格式和流模式前检查占用情况。启动与重连不应用预设。

实时电平与音量推子竖向并排显示在设备控制页各通道中，使用 Windows WASAPI 输入和输出回环读取，计算每路峰值。数据仅在内存中处理，不保存录音。输出回环表示电脑发送到声卡的声音，不包括声卡硬件直通监听。取消“实时电平”、最小化窗口或进入其他页面时暂停读取；驱动设置修改前自动释放采集流。

接口中安全模式使用 0x10000 标志位，输出格式使用驱动枚举的 ID；写入后读取设备实际值。电平读取不修改通道音量或添加效果器。

验证：原厂状态已在真实设备读取，设置使用当前值写入并回读；不同模式在隔离模拟中切换验证。实时电平已从真实声卡获取输入数据和输出回环数据。尚未进行长时间音频稳定性测试。
